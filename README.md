## ✨ Overview
The **Event Guest Counter** is a PHP/MySQL web application that automates guest counting for large events.  
It works like a digital registration system by scanning QR codes issued by event organizers, ensuring accurate and efficient tracking of attendees.

---

## ⚙️ How It Works
- Admins can create, manage, and generate event QR codes.  
- Guests are counted by scanning their admission tickets.  
- The system validates entries and tracks crowd volumes in real time.

## 👩‍💼 Management Features

### General
- Admin login required to generate tickets and print codes.  

### Public/User Facing
- Guests can view event crowd volumes.  

### Admin Facing
- Generate, print, update, and delete events.  
- Reset counters for new sessions.  
- Manage admission tickets and codes.
